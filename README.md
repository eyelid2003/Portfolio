## 🧩 Overview

This portfolio website represents my profile, including:
- Academic achievements,
- Technical skills,
- Full-stack development projects,
- Resume download option, and
- Contact details.

It has been developed with **TailwindCSS**, **HTML**, **JavaScript**, and includes **GSAP animations** for an engaging user experience.

---

## ✨ Features

✅ **Modern UI:** Gradient backgrounds and smooth transitions using TailwindCSS.  
✅ **Responsive Design:** Fully adaptable for all screen sizes (desktop, tablet, mobile).  
✅ **Animated Cursor & Effects:** Custom animated pointer and hover transitions.  
✅ **Interactive Navbar:** Responsive navigation with smooth scroll and mobile menu toggle.  
✅ **Education Timeline:** Stylish 3-step vertical timeline for education history.  
✅ **Skills Section:** Progress bars showing expertise level in various technologies.  
✅ **Project Showcase:** Flip-card 3D project display with tech stack and GitHub links.  
✅ **Resume Download:** One-click option to download PDF resume.  
✅ **Deployed on Netlify:** Fast and reliable hosting with custom domain.

## 🚀 How to Run Locally

1. **Clone this repository**
   ```bash
   git clone https://github.com/eyelid2003/portfolio.git
````

2. **Navigate into the project directory**

   ```bash
   cd portfolio
   ```

3. **Open the project**

   * Simply open `index.html` in any browser
   * OR use a local server (e.g., Live Server in VS Code)

That’s it! 🎉
